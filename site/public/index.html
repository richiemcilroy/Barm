Write TypeScript. Ship a tiny native binary.

Barm is a TypeScript-shaped language built for coding agents. It checks every line, explains each error with a fix, and compiles to a native program that keeps pace with Rust.

How it works

Barm reads like the TypeScript you already know. The difference is what happens when you build it.

1

Write TypeScript

Same syntax, Bun's server API and a Node-style standard library. If you (or your agent) can write TypeScript, you can write Barm.

// hello.barm
Bun.serve({
  port: 3000,
  fetch(req) {
    const url = new URL(req.url)
    return new Response(`Hello from ${url.pathname}`)
  },
})
2

Barm checks it

Anything that looks like TypeScript behaves like TypeScript, or it's an error with a code, a reason and a fix. Calls that can fail are marked with try, so you can see where errors go.

$ barm build hello.barm
error[T0831] hello.barm:4:17: `new URL` can throw `TypeError`; mark the call `try` to pass the error on, or catch it
    4 |     const url = new URL(req.url)
  why: errors are values in Barm: every call that can fail is marked, so control flow is visible
  fix[safe]: pass it on: `try new URL(req.url)`

add the try and it builds

3

You get a native binary

Barm turns your program into C and hands it to your system's C compiler. There's no VM and no garbage collector: memory is reference-counted, and you ship one small file.

$ barm build hello.barm -o hello
build: hello
$ ./hello &
$ curl localhost:3000/barm
Hello from /barm

142 KB, rebuilt in 0.25 s

What's different from TypeScript

Barm drops the parts of TypeScript that make programs hard to reason about or slow to run.

  • No any, null or == Types are sound. Unions must be narrowed before you use them, and a switch must cover every case.
  • Real integers int and f64 are separate types, and integer overflow stops the program instead of losing precision.
  • Data is copied, not shared Arrays, records and maps are values. To change a caller's value, a function takes an inout parameter.
  • Checked errors A function says what it throws, and every call that can fail is marked with try.

Try it

You need Rust to build the compiler and a C compiler (clang or gcc). Barm is early: command-line programs and web servers work today, and async I/O, TLS and HTTP/2 are still to come.
